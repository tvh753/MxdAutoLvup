# 🍁 枫叶挂机控制台 · MxdAutoLvup

面向**冒险岛怀旧服**（MapleStory）的自动化升级挂机工具。通过**后台窗口截图 + 模板识别 + 颜色识别**的方式，自动完成：找怪、攻击、放技能、喝药、拾取、巡逻走位、爬绳、地图包路线导航等一系列操作，并提供一个深色游戏风格的图形控制台（GUI）。

> ⚠️ 本项目仅用于学习交流（图像处理、模板匹配、自动化脚本等），请勿在游戏官方服务器或违反游戏规则的场景中使用。

---

## ✨ 功能特性

| 模块 | 说明 |
| --- | --- |
| 🪟 后台截图 | 基于 `PrintWindow` 的后台截屏，不依赖前台焦点即可识别画面 |
| 👾 模板识别 | 框选怪物/玩家模板，OpenCV 多模板匹配 + NMS 去重，标注实时识别结果 |
| ❤ 资源监控 | 框选 HP/MP/EXP 状态条，按颜色自适应识别百分比，自动喝药、停机保护 |
| 🎮 自动战斗 | 攻击 / 技能轮换 / 追击 / 脱离 / 巡逻随机跳跃 / 自动拾取 |
| 🗺 颜色路线 | 在小地图上用不同颜色绘制路线（走/跳/爬绳/瞬移/终点/停止），录制一次、处处复用 |
| 🪢 爬绳导航 | 对准绳 X 轴 → 停步 → 跳+↑ 抓绳 → 持续攀爬，失败自动退开重试 |
| 📦 地图包 | 每个地图独立的「底图 + 颜色路线 + 怪物模板」打包管理，随配置热切换 |
| ⏱ 定时休息 | 挂机时长随机 ±3 分钟，到点走到路线上「停止标记」休息后自动继续 |
| 🔒 防误操作 | 游戏窗口失焦自动暂停按键、按键可后台发送（DirectInput） |

## 🧰 环境要求

- **Windows 10/11**
- **Python 3.9+**（64 位）
- 依赖库见 `requirements.txt`：

```
opencv-python
numpy
Pillow
pywin32
pydirectinput
```

安装依赖：

```bash
pip install -r requirements.txt
```

> 注：`pydirectinput` 依赖 `pywin32`；如游戏以**管理员权限**运行，建议也以管理员权限启动本脚本，否则部分按键可能无法发送到游戏窗口。

## 🚀 快速上手

1. **启动**
   ```bash
   python main.py
   ```
2. **绑定游戏窗口**：在「目标」页选择游戏窗口 → 点【绑定】。
3. **框选怪物模板**：点【📷 框选怪物模板】→ 在实时画面中框选怪物本体 → 命名保存。
   （建议框选 1~3 种刷怪点常见的怪物。）
4. **校准状态条**（可选）：满血/满蓝时框选完整 HP / MP / EXP 条，颜色自动识别。
5. **配置按键**：切到「按键」页，点击输入框 → 按键盘按键即可绑定
   （普通攻击、技能、红蓝药、拾取、移动、跳跃、抓绳、传送）。
6. **绘制巡逻路线**（可选，强烈推荐）：
   - 【🧭 校准小地图】框选游戏内小地图区域（自动采样玩家黄点颜色）；
   - 【📷 录制小地图】录底图 → 【🎨 绘制路线】用颜色画出行走路线；
   - 勾选「启用路线巡逻」，保存为地图包。
7. **启动挂机**：点【▶ 启动挂机】（或按 `F8`），`F9` 暂停/恢复。

## 🎨 绘制路线（颜色路线 v5）

在「路线绘制器」中，用左侧色板选择**动作颜色**，然后在底图上拖动绘制：

| 颜色 | 动作 | 颜色 | 动作 |
| --- | --- | --- | --- |
| 红 | 左走 | 蓝 | 右走 |
| 橙 | 左跳 | 青 | 右跳 |
| 黄绿 | 下跳 | 品红 | 原地跳 |
| 浅绿 | 停止（休息点） | 黄 | 终点（完成一圈） |
| 粉 | 上瞬移 | 紫 | 下瞬移 |
| 深绿 | 左瞬移 | 棕色 | 右瞬移 |
| 灰 | 上爬绳 | 淡黄 | 下爬绳 |

操作小技巧：

- **按住 Shift 拖动** = 画直线，并可吸附水平/垂直（画平台横线、绳子竖线很好用）；
- 右键 = 撤销上一笔；「橡皮擦」可以擦掉画错的线；
- 平台画横线、绳子画竖线，路线的宽容度高（自动按最短路经寻点）。

## 🛠 技术原理

```
┌────────────┐   PrintWindow   ┌───────────┐   BGR 帧
│  游戏窗口   │ ───────────────► │ 窗口截图    │ ────────────►
└────────────┘                  └───────────┘              │
                                                           ▼
                                     ┌─────────────────────────────┐
                                     │ Detector 模板匹配(NMS去重)    │
                                     │ ResourceMonitor 血蓝EXP识别   │
                                     │ ColorRouteNavigator 小地图定位 │
                                     └─────────────────────────────┘
                                                           │
                                     ┌─────────────────────────────▼
                                     │ BotEngine 决策线程（约15 FPS）│
                                     │  战斗 / 追击 / 巡逻 / 喝药 / 拾取│
                                     └─────────────────────────────┘
                                                           │
                                     ┌─────────────────────────────▼
                                     │ ActionController 动作控制器    │
                                     │  DirectInput 后台按键 + 连续移动│
                                     └─────────────────────────────┘
```

### 1. 后台截图 `window_capture.py`
`PrintWindow` API 后台抓取指定窗口（对 DirectX 游戏做了特殊处理），提供 `screenshot()` / `list_windows()`；截图失败时自动回退到引擎缓存帧。

### 2. 目标识别 `detector.py`
多模板匹配 + 置信度阈值 + **NMS（非极大值抑制）** 去重，输出怪物坐标、玩家坐标，供决策层使用。

### 3. 状态条监测 `resource_monitor.py`
把框选的 HP/MP/EXP 条区域转 HSV，统计彩色像素占比估算百分比（容错方向错位、满血溢出），支持热重载配置。

### 4. 颜色路线导航 `color_route.py`（核心算法）
- **路线编码**：加载绘制好的路线图，将每个像素与 14 种动作颜色的 BGR 距离做最近邻匹配，得到 `label` 标记图；
- **玩家定位**：`BGR 精确匹配 → ±2 容差 → ±4 连通域 → HSV 兜底` 四级策略，命中后最近邻追踪，黄点闪烁时用累积掩码兜底，多候选时「往返试探」定位；
- **滚动补偿**：大地图小地图会随玩家滚动，用录制底图中央 55% 区域做模板，`matchTemplate` 估计位移，把 live 坐标换算回底图坐标系；
- **寻路**：每帧取玩家点附近半径内的标记，按「距离 + 背后惩罚」评分选出目标动作；丢失时保持方向惯性、走「回归路线」绕回；
- **爬绳状态机**：`align → grab → climb / backoff`，到位先停步 0.15s → 原地跳+↑ 抓绳 → 检测 y 变化确认上绳 → 持续攀爬，失败退开重试、超次跳过。

### 5. 动作执行 `action_controller.py`
维护"连续按住"移动状态机（左/右/上/下），跳跃/技能等瞬态按键点按；全部走 `pydirectinput` 向游戏窗口发送。

### 6. 决策线程 `bot_engine.py`
独立线程约 15 FPS 运行主循环：截图 → 识别 → 决策（战斗/追击/巡逻/喝药/拾取）→ 执行；通过 `queue` 向 GUI 推送实时标注帧与日志，`config.json` 支持运行时热加载。

### 7. 配置管理 `config_manager.py`
`config.json` 集中管理窗口标题、按键映射、识别阈值、状态条区域、巡逻参数、挂机时长等；`ConfigManager` 负责读写与版本迁移。

## ⚙️ 配置说明（config.json）

关键配置节：

```jsonc
{
  "window_title": "MapleStory",        // 绑定的游戏窗口标题（模糊匹配）
  "keys": { "attack": "ctrl", ... },   // 按键映射（pydirectinput 键名）
  "thresholds": {                       // 识别与策略参数
    "match": 0.75,                      // 模板匹配置信度阈值
    "hp_potion": 50,                    // 红药触发百分比
    "attack_range": 160,                // 攻击距离(px)
    "chase_range": 250,                 // 追击距离(px)
    "off_route_tol": 30,                // 偏离路线容差(px)
    ...
  },
  "options": {                          // 行为开关
    "use_skill_rotation": true,
    "pause_on_unfocus": true,
    "stop_on_low_hp": true,
    ...
  },
  "hp_bar": { "x": 0, "y": 0, "w": 0, "h": 0 },  // 校准后的状态条区域
  "detect_region": null,                // 检测区域（null=全屏）
  "patrol": {                           // 巡逻/地图包
    "enabled": false,
    "minimap": { "x": 0, "y": 0, "w": 0, "h": 0 },
    "player_dot_color": [60, 230, 255], // 小地图玩家黄点 BGR
    "current_map": "", "route_path": ""
  },
  "schedule": { "enabled": false, "duration_min": 60 },  // 定时休息
  "monster_templates": []               // 怪物模板列表
}
```

GUI 中的每个滑块/开关修改都会实时写入 `config.json`，下一次引擎循环自动生效（无需重启）。

## 📦 地图包（Map Pack）

一个地图包 = 一个小地图的完整"作战资料"，保存为 `maps/<地图名>/`：

- `minimap.png`：录制的小地图底图（滚动补偿基准）；
- `route.png`：颜色路线图（绘制一次，永久复用）；
- `profile.json` + `monsters/`：绑定该地图的怪物模板；
- 玩家模板全局共用。

GUI 中「保存地图包」会把当前小地图 + 路线 + 怪物模板整体打包；「加载地图包」一键恢复该地图全部配置（含按键同步），非常适合**多图刷怪**场景。

## ❓ 常见问题

**Q1：识别不到怪物 / 识别率低？**
- 重新框选怪物模板（避开血条数字、选特征明显的部位）；
- 调低「参数」页的「匹配阈值」；在怪物出没区域框选「检测区域」可提速。

**Q2：找不到小地图玩家黄点？**
- 重新【🧭 校准小地图】（会自动重新采样玩家点颜色）；
- 调大参数页「玩家点面积」；确认框选范围只含地图区域、不含标题文字。

**Q3：游戏画面黑屏 / 截不到图？**
- 确认游戏窗口未被最小化；部分全屏模式请改用**窗口化**运行；
- `PrintWindow` 对部分渲染引擎可能失效，可把游戏切换为无边框窗口。

**Q4：按键没反应？**
- 按键输入框点击后重新绑定；游戏以管理员运行时，脚本也需以管理员运行；
- 检查「行为开关」里「游戏失焦时暂停按键」是否误触发（鼠标点击游戏窗口即可恢复）。

**Q5：爬绳抓不住绳子？**
- 绳点应画在绳子的 **X 轴正中**、Y 取目标高度；调大「抓绳容差」；
- 确认上/下键已绑定，且游戏内"按住上+跳"确实能抓绳（部分职业/版本有差异）。

**Q6：路线巡逻越走越偏？**
- 重新【📷 录制小地图】底图，确保与当前地图同一区域；
- 路线尽量画在平台/地形的水平线上，避免画到墙上。
