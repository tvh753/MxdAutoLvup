# 📦 Windows 打包操作指南（MxdAutoLvup → 单文件 exe + zip）

> 本文档把「把本项目打包成 Windows 可执行程序并压缩成压缩包」的完整流程、
> 每一条命令及其含义整理成文，方便后续学习与复现。

---

## 一、整体流程概览

```
① 代码适配打包环境（frozen 判断）
        ↓
② 安装 PyInstaller
        ↓
③ 执行 PyInstaller 打包（onefile 单文件 / windowed 无控制台）
        ↓
④ 冒烟验证 exe（可选）
        ↓
⑤ 压缩成 zip
        ↓
⑥ 清理中间产物
```

打包产物：

| 产物 | 说明 |
| --- | --- |
| `dist/MxdAutoLvup.exe` | 单文件可执行程序（含全部依赖，目标机免装 Python） |
| `MxdAutoLvup_win64.zip` | exe 的压缩包，方便分发 |
| `MxdAutoLvup.spec` | PyInstaller 配置文件（每次构建自动生成，可删） |
| `build/` | 构建中间目录（可删） |

---

## 二、第 ① 步：代码适配打包环境（关键！）

**为什么要改？**
PyInstaller 单文件模式会把程序**解压到系统临时目录**运行。原代码用
`__file__` 推导项目根目录，打包后会指向临时目录 → 程序写出的
`config.json` / `maps/` / `templates/` 会落在临时目录，**关掉就丢失**。

**改法**（`core/config_manager.py` 顶部）：

```python
import json, os, copy, shutil
import sys   # ← 新增

if getattr(sys, "frozen", False):
    # PyInstaller 打包后：以 exe 所在目录为根，保证配置文件与 exe 同级可写
    ROOT = os.path.dirname(sys.executable)
else:
    ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
TEMPLATE_DIR = os.path.join(ROOT, "templates")
```

**知识点：**
- `sys.frozen == True` 表示当前运行在 PyInstaller 打包出的程序里；
- `sys.executable` = exe 自身路径，取它所在目录就是「exe 放在哪，配置就生成在哪」；
- 这样用户把 exe 解压到任意文件夹都能正常保存配置。

## 三、第 ② 步：安装 PyInstaller

```bash
pip install pyinstaller
```

验证是否装成功：

```bash
python -m PyInstaller --version
# 例如输出：6.22.2
```

## 四、第 ③ 步：执行打包

在**项目根目录**（`main.py` 所在目录）执行：

```bash
python -m PyInstaller \
    --noconfirm \
    --clean \
    --onefile \
    --windowed \
    --name MxdAutoLvup \
    --hidden-import win32timezone \
    main.py
```

### 各参数含义（便于理解）

| 参数 | 含义 |
| --- | --- |
| `python -m PyInstaller` | 以模块方式调用（避免 PATH 未加脚本目录） |
| `--noconfirm` | 目录已存在时自动覆盖，不弹确认 |
| `--clean` | 构建前清理缓存，保证干净构建 |
| `--onefile` | 打包成**单文件** exe（另一模式是 `--onedir` 文件夹） |
| `--windowed` | GUI 程序**不弹黑色控制台窗口**（若去掉，会多一个黑框） |
| `--name MxdAutoLvup` | 生成的 exe 名称 |
| `--hidden-import win32timezone` | pywin32 的坑：某些模块运行期才被 import，静态分析抓不到，需手动声明。缺失时启动可能报 `ModuleNotFoundError: win32timezone` |
| `main.py` | 程序入口脚本 |

> 常用配套参数补充（本项目没用到，但值得了解）：
> - `--icon 图标.ico`：自定义 exe 图标；
> - `--onedir`：打包成「exe + _internal 库目录」，启动更快、免反复解压，但分发是一整个文件夹；
> - `--exclude-module tkinter` 等：剔除用不到的模块以减小体积。

### 打包完成标志

日志末尾出现以下内容即成功：

```

Build complete! The results are available in: D:\test_demo\MxdAutoLvup\dist
```

## 五、第 ④ 步：冒烟验证（可选）

确认 exe 确实能启动（不闪退）：

```bash
cd dist
start "" MxdAutoLvup.exe      # 启动程序
tasklist | findstr /i MxdAutoLvup   # 查看进程是否在运行
taskkill /f /im MxdAutoLvup.exe     # 测试完结束进程
```

⚠ 注意：用 `start ""` 在一条命令里串 `tasklist` 时，GUI 进程会**占用管道句柄**
导致命令一直不返回超时。建议**分三条命令单独执行**，或用脚本重定向输入输出。
（本项目打包时用的就是这个方式，能起能进程存活即通过。）

---

## 六、第 ⑤ 步：压缩成 zip

`Compress-Archive` 用 PowerShell 完成，一条命令：

```bash
powershell -NoProfile -Command "Compress-Archive -Path 'D:\...\dist\MxdAutoLvup.exe' -DestinationPath 'D:\...\MxdAutoLvup_win64.zip' -CompressionLevel Optimal -Force"
```

**注意坑：** 在 cmd.exe 里直接内联带 `\` 的 Windows 路径和引号很容易被转义弄坏，
输出只是「回显命令」却不执行。更稳妥的写法是**把命令写进 .ps1 脚本再执行**：

```powershell
# _tmp_zip.ps1
Compress-Archive -Path 'D:\test_demo\MxdAutoLvup\dist\MxdAutoLvup.exe' `
                 -DestinationPath 'D:\test_demo\MxdAutoLvup\MxdAutoLvup_win64.zip' `
                 -CompressionLevel Optimal -Force
```

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File _tmp_zip.ps1
```

参数说明：
- `CompressionLevel Optimal`：压缩率优先（速度慢些、体积小些）；追求快可用 `Fastest`；
- `-Force`：已存在同名 zip 时直接覆盖；
- 本项目 exe ≈ 74 MB（OpenCV 库很大），zip ≈ 70 MB（exe 内部已是压缩数据，二次压缩空间有限）。

---

## 七、第 ⑥ 步：清理中间产物

```bash
del /f /q _tmp_zip.ps1 MxdAutoLvup.spec
rd /s /q build
```

保留 `dist/MxdAutoLvup.exe` 作为交付物。

---

## 八、最终交付物与使用须知

- **`dist/MxdAutoLvup.exe`** —— 双击即用的单文件程序（免 Python 环境）；
- **`MxdAutoLvup_win64.zip`** —— 分发用压缩包。

使用提醒：
1. 解压到**独立文件夹**再运行：`config.json`、`maps/`、`templates/` 会在 exe 同目录生成；
2. 游戏以管理员运行时应「以管理员身份运行 exe」，否则按键发不进游戏；
3. PyInstaller 单文件程序可能被**杀软误报**，加入信任/白名单即可；
4. onefile 每次启动需数秒解压，属正常现象；
5. 重打包前记得先把 `build/` 和 `.spec` 清掉（`--clean` 已自动处理大部分缓存）。

---

## 九、一键复现命令（浓缩版）

```bash
# 1. 安装
pip install pyinstaller

# 2. 打包（项目根目录）
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
    --name MxdAutoLvup --hidden-import win32timezone main.py

# 3. 压缩（用 ps1 脚本避免 cmd 引号坑）
powershell -NoProfile -ExecutionPolicy Bypass -File _tmp_zip.ps1

# 4. 清理
del /f /q MxdAutoLvup.spec
rd /s /q build
```
